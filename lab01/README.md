## Как запустить

Проверено на Python 3.14.0, OC: Windows 10 Pro, терминал: PowerShell, IDE: Visual Studio Code.

```powershell
cd lab01
python --version
python hello.py
python profile.py
python workload.py
python debug.py
python swap.py
python variant.py
python variant_discount.py
```

Если команда `python` не найдена, используйте `py` вместо `python`.
Дробные числа вводятся с точкой (`10.5`), запятая вызовет `ValueError`.

В корне проекта лежит `.gitignore`
(исключает `__pycache__`, виртуальные окружения и файлы IDE).

## Индивидуальный вариант 11: «Магазин растений»

Позиции варианта: **Саженцы** и **Горшки**.

### Собственный пример заказа (расчёт вручную до запуска)

Заказ «Весенний», заказчик Анна.

| Позиция | Количество | Цена, руб. | Стоимость, руб. |
|---|---|---|---|
| Саженцы | 4 | 23.50 | `4 * 23.50 = 94.00` |
| Горшки | 1 | 145.50 | `1 * 145.50 = 145.50` |

- товары без доставки: `94.00 + 145.50 = 239.50`;
- доставка: `12.00`;
- итого с доставкой: `239.50 + 12.00 = 251.50`;
- всего единиц: `4 + 1 = 5`;
- внесено `300.00`, сдача: `300.00 - 251.50 = 48.50`.

Значения посчитаны до запуска, затем `python variant.py` с этими же данными
вывел `94.00`, `145.50`, `239.50`, `251.50`, количество `5` и сдачу `48.50` —
совпало.

### Контрольный пример из условия

Заказ «Магазин растений», заказчик Мария.

| Позиция | Количество | Цена, руб. | Стоимость, руб. |
|---|---|---|---|
| Саженцы | 3 | 12.50 | `3 * 12.50 = 37.50` |
| Горшки | 2 | 20.00 | `2 * 20.00 = 40.00` |

- товары без доставки: `37.50 + 40.00 = 77.50`;
- доставка: `10.00`;
- итого с доставкой: `77.50 + 10.00 = 87.50`;
- всего единиц: `3 + 2 = 5`;
- внесено `100.00`, сдача: `100.00 - 87.50 = 12.50`.

Фактический вывод программы совпал со всеми значениями: `37.50`, `40.00`,
`77.50`, `87.50`, количество `5`, сдача `12.50`.

## Объяснения

**Строка и число.** `"2"` — строка из одного символа, `2` — целое число.
`"2" + "3"` склеивает строки и даёт `"23"`, а `2 + 3` даёт `5`. `input()`
всегда возвращает строку, поэтому для расчётов нужно явное преобразование
`int()` или `float()`; `type(value)` показывает текущий тип.

**Порядок вычислений.** Сначала умножение и деление, затем сложение и
вычитание, слева направо при равном приоритете; скобки меняют порядок.
Поэтому `4 + 7 + 10 / 3` равно `14.333…`, а `(4 + 7 + 10) / 3` равно `7.0`.

**Временная переменная при обмене.** Присваивание затирает старое значение.
Если сразу записать `first_room = second_room`, название первой аудитории
потеряется. `temporary_room` хранит его, пока идёт обмен: сначала сохраняем
первое значение, затем переносим второе в первую переменную и возвращаем
сохранённое значение во вторую.

**Форматирование денег.** Спецификация `:.2f` в f-строках выводит ровно два
знака после точки и округляет по правилам Python, поэтому `77.5` выводится
как `77.50`. Выравнивание задаётся шириной поля: `{name:<24}` — по левому
краю, `{value:>16.2f}` — по правому краю с двумя знаками.

**Почему карточка выводится в конце.** Все семь значений сначала
запрашиваются и сохраняются в переменные, и только потом выводится готовая
карточка — так подсказки ввода не перемешиваются с результатом.
