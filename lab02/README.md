## Задание 3: прогноз результата

Прогнозы записаны до запуска, затем значения проверены в Python.

| Выражение | Прогноз | Python | Объяснение |
|---|---|---|---|
| `2 + 3 * 4` | `14` | `14` | сначала умножение, затем сложение |
| `(2 + 3) * 4` | `20` | `20` | скобки меняют порядок действий |
| `17 // 5` | `3` | `3` | целая часть от деления |
| `17 % 5` | `2` | `2` | остаток: `17 - 3 * 5` |
| `-7 // 2` | `-4` | `-4` | `//` округляет вниз, к меньшему числу |

Различий между прогнозом и результатом нет. Отдельно про `-7 // 2`: частное
равно `-3.5`, округление вниз даёт `-4`, а не `-3`. Проверка через остаток:
`-7 == (-7 // 2) * 2 + (-7 % 2)`, то есть `-7 == -8 + 1`. Выражение `-7 % 2`
в Python равно `1`, потому что остаток берётся неотрицательным.

поэтому отдельное условие не требуется.

## Объяснения

**`/` и `//`.** Обычное деление `/` всегда даёт `float`: `17 / 5` равно `3.4`.
Деление `//` отбрасывает дробную часть, но не «к нулю», а вниз, к меньшему
числу: `17 // 5` равно `3`, `-7 // 2` равно `-4`. Поэтому `//` подходит для
полных часов, минут и целых тетрадей.

**Остаток.** `a % b` — это то, что осталось после выделения целых `b`:
`a == (a // b) * b + a % b`. Для положительных чисел остаток лежит от `0`
до `b - 1`. В `time_parts.py` остаток от деления на 3600 даёт «лишние» секунды,
которые затем делятся на 60; остаток от деления на 60 — это секунды. В
`variant.py` остаток `total_pages % pages_per_notebook` показывает, сколько
страниц не попало в полную тетрадь.

**Почему `:.2f` не устраняет неточность `float`.** `float` хранит дроби
приближённо: `0.1 + 0.2` равно `0.30000000000000004`. Формат `:.2f` только
округляет число при выводе, само значение в памяти не меняется, и ошибка
может накопиться в следующих вычислениях. В задачах о деньгах поэтому
используются целые рубли (или копейки), а не `float`.

**Формула `ceil` без условий.** Для неотрицательного `total` и положительного
`capacity` выражение `(total + capacity - 1) // capacity` даёт минимальное
число единиц, которого хватит для всего объёма. Слагаемое `capacity - 1`
«поднимает» результат на единицу только тогда, когда есть остаток.
