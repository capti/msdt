## Индивидуальный вариант 11

Чётные элементы разделить на 2 целочисленно, нечётные оставить без изменений.

Контрольная матрица `[[-2, 0, 3], [4, -5, 6]]` → `[[-1, 0, 3], [2, -5, 3]]`:
`-2 // 2 = -1`, `0 // 2 = 0`, `3` нечётное, `4 // 2 = 2`, `-5` нечётное, `6 // 2 = 3`.

## Вопросы к защите

**Какую ошибку выявляет таблица 2×3.** Таблица 2×3 показывает, что первый индекс —
строка, второй — столбец. При `[[0] * 3] * 2` все строки указывают на один и тот же
объект `[0, 0, 0]`: запись в `matrix[0][0] = 7` меняет и вторую строку, получается
`[[7, 0, 0], [7, 0, 0]]` вместо `[[7, 0, 0], [0, 0, 0]]`. Кроме того, при непустой
таблице нельзя предполагать квадратную форму: реальную длину строки нужно брать из
`len(matrix[0])`, иначе суммы столбцов будут неверными.

**Почему нельзя повторять одну изменяемую строку.** Конструкция `[[0] * columns] * rows`
создаёт `rows` ссылок на один внутренний список. Внутренние списки изменяемы, поэтому
изменение любой ячейки затронет все строки сразу, и данные «съедут». Независимые строки
создаются списковым включением: `[[0] * columns for _ in range(rows)]`.

**Чем копия внешнего списка отличается от копирования строк.** `matrix.copy()`
(или срез `matrix[:]`) копирует только внешний список: новые ячейки указывают на те же
внутренние списки, и изменение `copy[0][0]` меняет и исходную матрицу. Независимая копия
таблицы чисел строится как `[row.copy() for row in matrix]` — копируются и строки, тогда
изменения в копии не затрагивают оригинал (это проверяется в `test_table.py`).
